# 支持范围 / Support

本地验收环境：Windows 11、Node.js 24.15.0、npm 11.12.1、Python 3.12.14、Matplotlib 3.9.4、FontTools 4.66.1、Playwright 1.58.2；浏览器为 Chromium 145.0.7632.6（revision 1208）和 Firefox 146.0.1（revision 1509）。Linux 的相同依赖 CI 已配置，远端实际结果待发布后取得。未执行的平台不列为已验证支持。

## 数值与位置

`matplotlib-text-svg-v1` 读取保留的 text/tspan 和基本几何描边，识别绝对长度、相似变换、局部 defs/use 与受限 clipPath。每个对象的文字和描边独立计数；零字号/隐藏对象被排除。最终字号和线宽从完整最终变换计算，`pt = CSS px × 72/96`。对象的完整变换为 `R × V × inverse(rootScreen) × nodeScreen`；根变换只应用一次。

普通可信 DejaVu Sans 2.35 的已知字形使用哈希固定资产。其他字体、缺字形或非普通体的可用数值与定位能力分别报告，不能用近似位置声称精确。不可逆/非相似变换、非缩放描边等未支持数值保持 unassessed。路径文字不会反推字号。

尺寸指最终视口；变换后的对象可以越界，数值与实际范围仍保留，四幅图和标注按同一视口裁剪。报告明确超出视口，未知 bounds 显示无法定位而不绘制假框。两条角色记录不会因 objectId 相同被合并。

## 安全与状态

脚本、事件属性、实体与非标准 DTD、外链、输入图像、嵌套活动内容等被拒绝。Matplotlib 的固定 SVG 1.1 公共 DOCTYPE 在解析前移除，不加载 DTD。未知视觉能力停用全部预览和测量。严格入口只接受 SVG 文件，离线 PNG payload 仅由应用自己生成和回放，文件入口不接受图片或任意 JSON 快照。

状态包括 complete、partial、cancelled、timeout、engine-error、limited；计数保持 discovered = measured + unassessed + excluded + pending。枚举未完成时不把当前数量当作整图分母。配色只作人工模拟，不自动判定通过。

## 固定资源上限

| 项目 | 上限 |
|---|---:|
| 输入字节 | 2,097,152（2 MiB） |
| 元素（含根） | 4,096 |
| 深度 | 64 |
| 单属性值 | 65,536 UTF-8 字节 |
| 单 path 数据字节 | 524,288 |
| 原始 path 命令总数（含隐式参数组） | 4,096 |
| 单 path / polyline / polygon 等效命令 | 1,024 |
| 展开后的矢量命令 | 2,048 |
| ceil 视口像素面积 × drawWeight | 128,000,000 |
| 文字 | 131,072 UTF-16 代码单元；补充字符占两个 |
| use 实例 | 2,000 |
| 最终宽/高 | 每边 1–500 mm |
| 每幅预览边长 | 2,048 CSS px |
| 每幅预览面积 | 4,000,000 px |
| 同时预览 | 四幅 |
| 测量软预算 | 15,000 ms；在下一检查点停止 |

最终毫米尺寸限制与像素限制同时生效。命令与工作成本由唯一安全解析器计算并私有绑定到不可变源对象；调用者传入的更严格限制沿测量和预览传递。复制 JSON 不能取得绘制资格。

展开命令逐次计入 use 与 clip，未引用 defs 不计为已绘制实例；基础几何 line/rect/circle/ellipse 分别按 2/5/6/6 命令计。drawWeight 每个几何计 2 个潜在 fill/stroke 绘制，每次 clip 几何计 1，直属 text/tspan UTF-16 字符计 2，带透明度的非几何容器增加 1；隐藏/透明内容也保守计入。这是工作量上界，不是可见对象统计。最终尺寸工作量超限返回 RASTER_WORK_LIMIT，四幅预览停用，JSON 和停用状态 HTML 仍可保存；缩小宽度可恢复。

原允许的 32,768 命令图在本轮整图栅格化实测中出现约 22 秒同步停顿，因此按响应门槛收紧输入。新上限仍须与实际压力记录一起评估，不能把拒绝当作成功测量。取消为协作式；同步浏览器调用本身不能被中途打断。压力验证用外部每 100 ms 事件回执和页面 50 ms 探针，门槛为回执 P95≤250 ms、max≤1,000 ms、timer 额外延迟≤500 ms、单次同步调用≤500 ms、取消/重新导入≤1,000 ms、测量≤16,000 ms。具体机器与浏览器会影响耗时。

## 预览和离线归属

四幅图均有独立工具 SVG 根、引用 ID、sourceMap 命中层与未过滤标注。原色保留安全源 SVG；三种模拟从同一图景的完整已合成 RGBA 进行双精度 sRGB 线性转换，Alpha 不变，再直接编码 straight-RGBA PNG。色块独立真值门槛为 RGB≤2/255、Alpha≤1/255。逐 paint 转色不会替代整图重叠语义。

一次只持有当前场景；绑定 PreparedSvg 身份、原始 SHA、安全 markup 摘要、revision、最终尺寸、字体 SHA、模型版本。转换串行，像素批次让出主线程。源 Canvas 完成提取后归零；临时 Image/Blob URL 随所属操作释放。最多保留一份原始 RGBA、一份正在转换 RGBA、一份 PNG 行编码缓冲及受界限约束的压缩/PNG字节；它们是显式中间缓冲，不冒充零额外开销。三张已完成 PNG 供显示和保存复用，所有权在最后预览销毁时失效。改变阈值复用同一测量和场景；改变输入/宽度撤销旧场景，迟到结果不能覆盖新 revision。

四幅实际就绪前 HTML 保存不可用。HTML 保存选中对象、结果、人工备注和已完成模拟 PNG；回放检查 PNG 签名、尺寸、字节上限和摘要，只显示已保存内容，不重新测量或转色。离线 bootstrap 复用唯一解析器重验安全字节、成本和稳定节点/引用对应，保留实际较严限制；不重新认证缺失的原始文件字节。停用报告不解析 SVG。摘要用于一致性检查，不是报告作者的密码学认证。原色回退字体的跨主机视觉边界见 README。

## 样本与验证

39 个合成文件覆盖 20 个主题；M20 是 01 和 21–39 共 20 个不同缺陷文件。安全与限值参数化变体单独验证，不计入 M20。测量值容差 0.01 pt，独立文字墨迹/度量包络和线框位置容差 1 CSS px；生成器使用导出参数与随项目分发的字体。FontTools 提供设计度量与字形轮廓，Pillow/FreeType 为 Linux Chromium 计算按 CSS 布局像素对齐的前进量与墨迹。Linux Firefox 使用带字距调整的分数字宽，按同一文字框的字号范围计算栅格墨迹，并在 SVG 布局中计入文字框的溢出墨迹。浏览器测试按操作系统和引擎预先选择对应的参考。水平边界计入文字前进量及伸出两端的墨迹，随后将四角变换到最终图件坐标。

人工视觉记录指代理逐图查看真实浏览器截图，明确记录检查者身份。自动矩阵、代理视觉复核和用户采用研究分别列出；用户访谈/采用研究尚未实施。

## 复现问题

提供浏览器和系统版本、最终图宽、导出参数及最小合成 SVG；避免上传包含私人信息的图件。说明预期值或 independent reference，并附 JSON 中状态和 reasonCodes。若修改测量、布局、预览或边界，重新运行相关双浏览器测试及受影响压力矩阵。
